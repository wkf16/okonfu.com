Ongoing Projects

Project 1: Air-Ground Heterogeneous Robot Cooperative Planning for Search and Rescue

Project Overview: In disaster events, search and rescue work primarily involves two parts: searching and rescuing. Aerial drones first search the unknown environment, and once victims are found, ground rescue vehicles perform path planning to find the shortest route. The aerial drones use a variant of the A* algorithm for search, while the ground drones use BIT* or other algorithms for optimal rescue path planning.

Project 2: FPGA Implementation of SoC Based on VexRisc-V

Project Overview: This is a topic for a national FPGA competition, requiring the implementation of basic peripherals (such as UART, GPIO). Currently learning computer organization principles and planning to implement an architecture based on AXI4+APB3.

Project 3: Image Super-Resolution Based on Attention Mechanism

Project Overview: Utilizing a cascaded residual structure and introducing channel attention mechanisms into the Transformer architecture to reconstruct images. Currently in the learning phase, and the full implementation is not yet fully understood. Working with neural networks sometimes feels a bit like alchemy – somewhat mysterious.
