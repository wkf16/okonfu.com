Top Project Achievements

ATOMIC Swarm Robot Platform - HKUST(GZ) ATOMIC Lab (Research Assistant) (May 2026 - present)

  • End-to-end swarm stack ownership across 4 layers: KiCad PCBs, 3D-printed housings, C firmware on nRF52833, Flask + Socket.IO web host. Indoor localization via HTC Vive Lighthouse v1 + TS4231 photodiodes, 50 Hz pose broadcast on bare-RADIO 2.4 GHz adv (no SoftDevice; firmware fits in 128 KB).
  • Designed and prototyped a monocular vision calibration & ground-truth rig: an ArUco quad-sheet anchors a metric world frame via homography (three more sheets extend coverage and catch base-station drift) and a YOLO detector localizes the robot, recovering world coordinates from one overhead photo. Single-frame repeatability ≈3 mm on markers, ≈22 mm on the robot. Double duty: a vision ground truth for Lighthouse accuracy, and the source of a refreshed affine calibration fed to the swarm over the existing OTA channel.
  • Shipped three PRs in onboarding sprint: #18 fix/webUI (viewport-fit map + target feedback), #19 feat/api (Flask REST/SSE API: POST target, GET pose stream, validated by automated trajectory test), #20 feat/ota (OTA affine-calibration push + status-broadcast scaffold + recalibration tooling).

Open-Yachiyo: AI-native desktop agent framework (300+ GitHub stars) (2026 - present)

GitHub: https://github.com/sdyzjx/open-yachiyo

  • Co-architect and core developer of a from-scratch implementation of the ReAct (Reason-Act-Observe) paradigm, with an Event Bus tool-calling chain and SSE JSON-RPC full-link observability for live, step-through inspection of in-flight agent runs; inspired by 『超かぐや姫！』.
  • The project produced two convictions. First, in the agentic-coding era the multiplier for AI productivity is decoupled architecture + top-down design + documentation-driven workflow; during the early phase it sustained a peak output of 15,000 lines/day.
  • Second, implementing the Reason-Act-Observe loop hands-on gave a genuine understanding of how an agent iterates decisions in uncertain environments.
  • National-level SRTP project; selected as Fuzhou University Outstanding Graduation Design.

Insole blanking robot with adaptive edge detection and FSPS-BIT* (2023 - 2024)

GitHub: https://github.com/HaoHaoRight/Robotics_of_ABB1200

  • A factory robotic-arm system for insole blanking with an FSPS-BIT* motion planner in 3-D operating space, benchmarked against RRT*, FMT*, Informed-RRT*, and BIT*.

Edge-AI Real-time Rice-Pest Monitoring and Collaborative Trapping System (2024 - 2026)

  • Built a 1,500-image, 12-class real-field dataset and a lightweight perception/deployment pipeline (Mixed Aggregation backbone, Ghost Conv pre-head, TensorRT on Jetson Xavier NX, ESP32 low-power actuation, LoRa multi-node mesh).
