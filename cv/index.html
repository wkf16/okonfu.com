Research and Engineering Projects

ATOMIC Swarm Robot Platform | HKUST(GZ) ATOMIC Lab

Research Assistant (May 2026 to Present)

  • Full stack swarm robotics infrastructure. Owned the complete swarm platform across four distinct layers: custom KiCad printed circuits, 3D printed mechanical housings, bare metal C firmware on the nRF52833, and a Flask web host powered by Socket.IO. Implemented indoor localization pairing HTC Vive Lighthouse stations with TS4231 optical sensors, broadcasting 50 Hz pose streams via direct 2.4 GHz radio packets without SoftDevice overhead to compress total firmware within 128 KB.
  • Visual verification and spatial calibration. Built an overhead monocular camera rig to establish an absolute spatial reference and correct base station drift. Mapped metric coordinates through homography from multi sheet ArUco marker grids while deploying a custom YOLO model to track robot positions from a single frame, achieving repeatability around 3 mm on markers and 22 mm on robots. This system provides visual ground truth for Lighthouse tracking while streaming refreshed affine calibration parameters to the swarm over the air.
  • Rapid system integration and deployment. Accelerated platform maturity during initial onboarding by shipping three core infrastructure milestones: overhauled the operator interface with responsive viewport mapping and live target feedback, architected a Flask REST and SSE streaming pipeline verified by automated trajectory testing, and established over the air deployment tooling to distribute runtime calibration data across the active fleet.

Open-Yachiyo: Desktop Agent Execution Framework

Core Architect (2026 to Present) | Open Source (300+ GitHub Stars) | GitHub

  • Runtime loop and execution architecture. Co architected a desktop runtime from scratch around the Reason, Act, and Observe paradigm. Designed an asynchronous Event Bus tool calling pipeline coupled with Server Sent Events and JSON RPC to provide granular, step by step execution traces and state observability for in flight agent decisions.
  • Modular system design. Engineered decoupled tool dispatch and structured context management layers to handle complex agentic workflows under uncertain environments, sustaining rapid feature scaling while maintaining clean system modularity.
  • Academic recognition. Funded as a National College Students Innovation and Entrepreneurship Project (SRTP) and selected as a Fuzhou University Outstanding Graduation Design.

Edge-AI Real-time Rice-Pest Monitoring and Robotic Trapping System

First Author | Published in Frontiers in Plant Science (IF 5.9, JCR Q1) (2024 to 2026)

  • Dataset and edge perception pipeline. Constructed a field dataset of 1,500 images across 12 distinct pest categories collected in natural agricultural environments. Designed an ultra lightweight detection network featuring a Mixed Aggregation backbone and Ghost Conv pre processing head, optimized via TensorRT for edge deployment on the NVIDIA Jetson Xavier NX alongside an ESP32 low power actuation subsystem and LoRa multi node mesh.
  • Empirical performance and validation. Achieved 96.1% mAP at 0.5 with 59.4 FPS directly on edge hardware, boosting inference speed by 19.6% over the standard YOLO baseline. Demonstrated superior noise robustness by securing the highest mAP in 6 out of 9 degraded field scenarios, with a closed loop latency of 14.8 ms and complete system latency of 36.8 ms.
  • Scholarly publication. Published as first author in Frontiers in Plant Science (Volume 2026, DOI: 10.3389/fpls.2026.1853368).

Industrial Robotic Arm for Insole Blanking with Adaptive Edge Detection

Robotics Researcher (2023 to 2024) | GitHub

  • Motion planning and simulation. Developed the FSPS BIT* motion planning algorithm operating within a 3D workspace for factory insole blanking, benchmarked comprehensively against traditional planners including RRT*, FMT*, Informed RRT*, and standard BIT*.
  • Implementation and intellectual property. Owned the core MATLAB algorithmic implementation and the UR5 robotic simulation environment. Research outcomes directly contributed to a co authored academic paper and a granted Chinese invention patent.
