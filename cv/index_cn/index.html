研究与工程项目

ATOMIC 集群机器人平台 | 香港科技大学（广州）ATOMIC 实验室

研究助理（2026 年 5 月至今）

  • 全栈集群机器人基础设施。 负责整个集群平台的四个层次：自主设计的 KiCad 电路板、3D 打印机械外壳、nRF52833 上的裸机 C 固件，以及基于 Flask 和 Socket.IO 的网页上位机。实现了室内定位：HTC Vive Lighthouse 基站配合 TS4231 光学传感器，通过直接的 2.4 GHz 无线数据包以 50 Hz 广播位姿，不使用 SoftDevice，使固件总体积压缩在 128 KB 以内。
  • 视觉校验与空间标定。 搭建了俯拍单目相机装置，用于建立绝对空间参考并校正基站漂移。通过多张 ArUco 标记板的单应性映射得到米制坐标，同时部署自训练的 YOLO 模型从单帧图像中追踪机器人位置，重复精度在标记上约 3 mm、在机器人上约 22 mm。该系统为 Lighthouse 定位提供视觉真值，并通过无线方式向集群下发更新后的仿射标定参数。
  • 快速系统集成与部署。 在入职初期交付了三项核心基础设施里程碑，加快了平台成熟：重做了操作界面，支持自适应视口地图和实时目标反馈；设计了经自动轨迹测试验证的 Flask REST 与 SSE 流式接口；建立了无线部署工具，可向运行中的整个车队分发运行时标定数据。
  • EWSN 2026 Swarm Chess 演示。 共同开发了 Swarm Chess：每枚棋子都是一台 AtomBot 机器人，LLM 智能体通过实体机器人集群下棋。智能体运行 ReAct 循环，只能通过四个棋类工具（读取棋盘、走子、摆盘、认输）感知和操作棋盘；棋盘管理引擎校验每一步棋，再由 WHCA* 多机器人路径规划器把棋步转换为机器人的目标点。支持智能体对智能体和智能体对人类两种模式，控制台、墙面和地面三块同步屏幕实时显示智能体推理、工具调用和机器人运动。以共同第一作者身份在德累斯顿 EWSN 2026 作口头 Demo 报告 [1]。

Open-Yachiyo：桌面智能体执行框架

核心架构师（2026 年至今）| 开源（GitHub 300+ Stars）| GitHub

  • 运行时循环与执行架构。 围绕 Reason、Act、Observe（推理、行动、观察）范式，从零共同设计了桌面运行时。设计了异步事件总线（Event Bus）工具调用流水线，结合 Server Sent Events 和 JSON RPC，为运行中智能体的决策提供细粒度的逐步执行轨迹和状态可观测性。
  • 模块化系统设计。 构建了解耦的工具分发层和结构化的上下文管理层，用于处理不确定环境下的复杂智能体工作流，在功能快速扩展的同时保持系统模块清晰。
  • 学术认可。 获国家级大学生创新创业训练计划项目（SRTP）立项资助，并入选福州大学优秀毕业设计。

Edge-AI 实时稻田害虫监测与机器人诱捕系统

第一作者 | 发表于 Frontiers in Plant Science（IF 5.9，JCR Q1）（2024 至 2026 年）

  • 数据集与边缘感知流程。 构建了在自然农田环境中采集的田间数据集，共 1,500 张图像、12 类害虫。设计了超轻量检测网络，采用 Mixed Aggregation 主干网络和 Ghost Conv 预处理头，经 TensorRT 优化后部署在 NVIDIA Jetson Xavier NX 边缘设备上，并配合 ESP32 低功耗执行子系统和 LoRa 多节点组网。
  • 实测性能与验证。 在边缘硬件上直接达到 96.1% mAP@0.5 和 59.4 FPS，推理速度比标准 YOLO 基线提升 19.6%。在 9 种退化田间场景中有 6 种取得最高 mAP，抗噪能力突出；闭环延迟 14.8 ms，系统整体延迟 36.8 ms。
  • 学术发表。 以第一作者在 Frontiers in Plant Science 发表论文（2026 年卷，DOI：10.3389/fpls.2026.1853368）。

基于自适应边缘检测的工业鞋垫冲裁机械臂

机器人研究员（2023 至 2024 年）| GitHub

  • 运动规划与仿真。 开发了在三维工作空间中运行的 FSPS-BIT* 运动规划算法，用于工厂鞋垫冲裁，并与 RRT*、FMT*、Informed-RRT* 和标准 BIT* 等传统规划器进行了全面对比。
  • 实现与知识产权。 负责核心 MATLAB 算法实现和 UR5 机器人仿真环境。研究成果直接支撑了一篇合著学术论文和一项已授权的中国发明专利。
