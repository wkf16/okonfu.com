主なプロジェクト

ATOMIC 群ロボットプラットフォーム – HKUST(GZ) ATOMIC Lab（リサーチアシスタント）（2026年5月～現在）

  • 群ロボットシステムの4層すべてをエンドツーエンドで担当：KiCad による PCB、3Dプリント筐体、nRF52833 上の C ファームウェア、Flask + Socket.IO の Web ホスト。屋内測位は HTC Vive Lighthouse v1 + TS4231 フォトダイオードで行い、ベア RADIO の 2.4 GHz アドバタイズで姿勢を 50 Hz でブロードキャスト（SoftDevice 不使用；ファームウェアは 128 KB に収まる）。
  • 単眼ビジョンによるキャリブレーション・グラウンドトゥルース装置を設計・試作：ArUco の4マーカーシートがホモグラフィによりメートル単位の世界座標系を固定し（追加の3枚で範囲を広げ、ベースステーションのずれを検出）、YOLO 検出器がロボットの位置を求め、俯瞰写真1枚から世界座標を復元する。単一フレームの再現性はマーカーで約 3 mm、ロボットで約 22 mm。二つの役割を兼ねる：Lighthouse 測位精度を評価するビジョン基準値、および既存の OTA チャネルで群に配信する更新版アフィンキャリブレーションの生成元。
  • 着任直後のスプリントで3件の PR を完成：#18 fix/webUI（ビューポートに合わせた地図表示＋目標点フィードバック）、#19 feat/api（Flask REST/SSE API：目標点の POST、姿勢ストリームの GET、自動軌道テストで検証）、#20 feat/ota（OTA によるアフィンキャリブレーション配信＋ステータスブロードキャストの骨組み＋再キャリブレーションツール）。

Open-Yachiyo：AIネイティブなデスクトップエージェントフレームワーク（GitHub 300+ stars）（2026年～現在）

GitHub：https://github.com/sdyzjx/open-yachiyo

  • 共同アーキテクト兼コア開発者として、ReAct（Reason-Act-Observe）パラダイムをゼロから実装。Event Bus によるツール呼び出しチェーンと SSE JSON-RPC による全経路の可観測性を備え、実行中のエージェントをリアルタイムにステップ単位で確認できる。『超かぐや姫！』に着想を得た。
  • このプロジェクトから二つの確信を得た。第一に、エージェント型コーディングの時代に AI の生産性を何倍にもするのは疎結合アーキテクチャ＋トップダウン設計＋ドキュメント駆動のワークフローである。初期段階では1日 15,000 行のピーク出力を維持した。
  • 第二に、Reason-Act-Observe ループを自らの手で実装したことで、不確実な環境でエージェントがどのように意思決定を反復するのかを本当に理解できた。
  • 国家級 SRTP（大学生創新訓練）プロジェクト；福州大学優秀卒業設計に選出。

適応的エッジ検出と FSPS-BIT* によるインソール打ち抜きロボット（2023 – 2024）

GitHub：https://github.com/HaoHaoRight/Robotics_of_ABB1200

  • インソール打ち抜き用の工場向けロボットアームシステム。3次元作業空間で FSPS-BIT* 動作計画器を用い、RRT*、FMT*、Informed-RRT*、BIT* と比較評価した。
  • FSPS-BIT* 計画器の MATLAB 実装と UR5 シミュレーション環境を担当し、論文 [2] および登録済み発明特許 [4] に貢献。

エッジ AI によるリアルタイム稲害虫モニタリング・協調捕獲システム（2024 – 2026）

  • 1,500枚・12クラスの実圃場データセットと、軽量な認識・デプロイパイプラインを構築（Mixed Aggregation バックボーン、Ghost Conv プレヘッド、Jetson Xavier NX 上の TensorRT、ESP32 による低消費電力駆動、LoRa マルチノードメッシュ）。
  • エッジハードウェア上で 96.1% mAP@0.5、59.4 FPS を達成（YOLOv13 ベースライン比で精度 +0.7%、速度 +19.6%）；劣化シーン9種中6種で mAP 最高；閉ループ遅延 14.8 ms ＋ エンドツーエンド遅延 36.8 ms。
  • 筆頭著者として Frontiers in Plant Science（IF 5.9、JCR Q1；Sustainable and Intelligent Phytoprotection、2026）に論文 [1] を発表。DOI：10.3389/fpls.2026.1853368。
