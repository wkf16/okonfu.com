研究・開発プロジェクト

ATOMIC 群ロボットプラットフォーム | HKUST(GZ) ATOMIC Lab

リサーチアシスタント（2026年5月～現在）

  • フルスタックの群ロボット基盤。 群ロボットプラットフォーム全体を4つの層にわたって担当：独自設計の KiCad 回路基板、3Dプリントの機構筐体、nRF52833 上のベアメタル C ファームウェア、Socket.IO を用いた Flask の Web ホスト。HTC Vive Lighthouse ベースステーションと TS4231 光センサを組み合わせた屋内測位を実装し、SoftDevice を使わず 2.4 GHz の無線パケットで姿勢を 50 Hz で直接ブロードキャストすることで、ファームウェア全体を 128 KB 以内に収めた。
  • 視覚による検証と空間キャリブレーション。 俯瞰の単眼カメラ装置を構築し、絶対的な空間基準を確立してベースステーションのずれを補正。複数枚の ArUco マーカーシートからホモグラフィでメートル座標を求め、独自の YOLO モデルで1フレームからロボットの位置を追跡し、再現性はマーカーで約 3 mm、ロボットで約 22 mm を達成。このシステムは Lighthouse 測位の視覚的な基準値を提供し、更新したアフィンキャリブレーションパラメータを無線で群に配信する。
  • 迅速なシステム統合と導入。 着任初期に3つの中核的な基盤マイルストーンを完成させ、プラットフォームの成熟を加速：操作画面を刷新してビューポートに応じた地図表示とリアルタイムの目標フィードバックを実現、自動軌道テストで検証した Flask REST と SSE のストリーミング基盤を設計、稼働中の全ロボットに実行時キャリブレーションデータを配信する無線デプロイツールを構築。
  • EWSN 2026 Swarm Chess デモ。 Swarm Chess を共同開発：チェスの駒一つひとつが AtomBot ロボットで、LLM エージェントが実機の群ロボットを通じて対局する。エージェントは ReAct ループで動作し、4つのチェス用ツール（盤面取得、指し手、配置、投了）を通じてのみ盤面を把握・操作する。盤面管理エンジンが各指し手を検証し、WHCA* による複数ロボット経路計画器がそれをロボットの目標点に変換する。エージェント対エージェントとエージェント対人間の2モードに対応し、コントロールハブ、壁面、床面の3画面を同期させてエージェントの推論、ツール呼び出し、ロボットの動きを表示する。共同筆頭著者として、ドレスデンで開催された EWSN 2026 にて口頭デモ発表を行った [1]。

Open-Yachiyo：デスクトップエージェント実行フレームワーク

コアアーキテクト（2026年～現在）| オープンソース（GitHub 300+ Stars）| GitHub

  • 実行ループと実行アーキテクチャ。 Reason、Act、Observe（推論・行動・観察）のパラダイムを軸に、デスクトップ向けランタイムをゼロから共同設計。非同期の Event Bus によるツール呼び出しパイプラインを Server Sent Events および JSON RPC と組み合わせ、実行中のエージェントの判断について、きめ細かなステップごとの実行トレースと状態の可観測性を提供。
  • モジュール化されたシステム設計。 疎結合なツールディスパッチ層と構造化されたコンテキスト管理層を構築し、不確実な環境での複雑なエージェントワークフローに対応。機能を素早く拡張しながら、システムのモジュール性を保った。
  • 学術的評価。 国家級大学生創新創業訓練計画（SRTP）プロジェクトとして採択・助成され、福州大学優秀卒業設計に選出。

Edge-AI リアルタイム稲害虫モニタリング・ロボット捕獲システム

筆頭著者 | Frontiers in Plant Science 掲載（IF 5.9、JCR Q1）（2024年～2026年）

  • データセットとエッジ認識パイプライン。 自然の農業環境で収集した 12 種類の害虫、計 1,500 枚の画像からなる圃場データセットを構築。Mixed Aggregation バックボーンと Ghost Conv 前処理ヘッドを備えた超軽量検出ネットワークを設計し、TensorRT で最適化して NVIDIA Jetson Xavier NX にエッジ実装。ESP32 による低消費電力駆動サブシステムと LoRa マルチノードメッシュを組み合わせた。
  • 実測性能と検証。 エッジハードウェア上で直接 96.1% mAP@0.5、59.4 FPS を達成し、標準的な YOLO ベースラインより推論速度を 19.6% 向上。9 種類の劣化した圃場シナリオのうち 6 種類で最高 mAP を獲得し、高いノイズ耐性を示した。閉ループ遅延は 14.8 ms、システム全体の遅延は 36.8 ms。
  • 学術発表。 筆頭著者として Frontiers in Plant Science に論文を発表（2026年巻、DOI：10.3389/fpls.2026.1853368）。

適応的エッジ検出を用いた工業用インソール打ち抜きロボットアーム

ロボティクス研究者（2023年～2024年）| GitHub

  • 動作計画とシミュレーション。 工場でのインソール打ち抜き向けに、3次元作業空間で動作する FSPS-BIT* 動作計画アルゴリズムを開発し、RRT*、FMT*、Informed-RRT*、標準 BIT* などの従来手法と総合的に比較評価。
  • 実装と知的財産。 中核となる MATLAB アルゴリズム実装と UR5 ロボットシミュレーション環境を担当。研究成果は共著の学術論文1本と登録済みの中国発明特許1件に直接つながった。
